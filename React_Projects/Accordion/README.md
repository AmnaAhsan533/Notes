## React Accordion Project

In this project, I built a dual-mode accordion to master conditional rendering and state synchronization in React. Single-selection mode uses a simple primitive state (`selected`) to store a single active item ID, while multi-selection mode uses an array state (`multiple`) and immutable array methods (`.indexOf` and `.splice`) to track several expanded items at once. By toggling a boolean flag (`enableMS`), the component dynamically switches its click handlers and conditionally renders the content using JavaScript's short-circuit `&&` operator, linking React's logic directly to dynamic CSS class names for smooth UI transitions.
