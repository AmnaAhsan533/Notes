# Random Color Generator Project

In this project, I built a random background color generator to understand React’s execution flow, state synchronization, and side effects using `useEffect`. The component handles two color formats—HEX and RGB—by maintaining a `typeOfColor` flag and a `color` string in state. When the color mode is toggled, a `useEffect` hook listens to the dependency change, automatically triggering the corresponding generation algorithm (`handleCreateHEX` or `handleCreateRGB`).
